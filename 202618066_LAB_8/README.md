## Part A — Decision Tree from Scratch

The manual classifier uses weighted Gini reduction to choose a feature and numeric threshold at each node, recursively creates children, and predicts the majority class at terminal leaves.

**Gini impurity:**

$$
Gini(S)=1-\sum_{k=1}^{K}p_k^2
$$

**Entropy (also implemented):**

$$
H(S)=-\sum_{k=1}^{K}p_k\log_2p_k
$$

**Weighted impurity and split gain:**

$$
I_{split}=\frac{N_L}{N}I(L)+\frac{N_R}{N}I(R),\qquad
Gain=I(parent)-I_{split}
$$

Candidate thresholds are midpoints between successive unique feature values. Stopping rules include `max_depth`, `min_samples_split`, `min_samples_leaf`, pure nodes, and no beneficial split. The notebook visualizes the tree structure and 2D, axis-aligned decision regions.

For the initial depth-3 tree, the root split was:

```text
variance <= 0.321235
```

The original depth-3 manual and Scikit-learn trees made **identical test predictions (zero disagreements)**, supporting the correctness of the manual splitting/prediction code.

A subsequent train-set hyperparameter search selected:

```python
max_depth = 8
min_samples_split = 2
min_samples_leaf = 1
```

This optimized manual tree achieved **98.18%** held-out test accuracy.

## Part B — Linear SVM from Scratch

The manual SVM fits a linear decision function:

$$
f(x)=w^Tx+b,\qquad \hat y=\operatorname{sign}(f(x))
$$

**Hinge loss:**

$$
L_i=\max(0,1-y_i(w^Tx_i+b))
$$

**Objective used in this project:**

$$
J(w,b)=\frac12\lVert w\rVert^2+\frac{C}{n}\sum_{i=1}^{n}L_i
$$

Batch subgradients are calculated from observations satisfying $y_if(x_i)<1$ and used to update the weights and bias:

$$
w\leftarrow w-\eta\,g_w,\qquad b\leftarrow b-\eta\,g_b
$$

The notebook shows the objective's training curve and 2D separating line $f(x)=0$, margins $f(x)=\pm1$, margin-violating samples, and misclassifications.

### Hyperparameter Findings

- **Regularization:** On the 2D training experiment, increasing `C` from 0.1 to 10 improved mean cross-validation accuracy from **69.74% to 87.51%**, while the measured proportion of margin violations decreased from **100.00% to 46.58%**.
- **Learning rate:** Tested `0.001`, `0.005`, `0.01`, and `0.05`; after 2,000 iterations, results were very similar at the displayed precision.
- **Iterations:** With `C=10` and learning rate `0.005`, the two-feature training objective stabilized near **3.942221** by approximately **500 iterations**.
- **Final four-feature comparison:** Using `C_manual=10`, learning rate `0.005`, and 2,000 iterations, the manual and Scikit-learn Linear SVMs achieved the same **97.09%** held-out accuracy with **zero prediction disagreements**.

Because the manual code uses **mean** hinge loss while `sklearn.svm.SVC` uses a **sum-based** formulation, the equivalent library setting was $C_{sklearn}=C_{manual}/n_{train}$.

## Key Observations and Limitations

1. **The manual algorithms agree closely with Scikit-learn.** The baseline depth-3 trees and final Linear SVMs produced zero test prediction disagreements in their respective comparisons.
2. **Greater model complexity is not automatically better.** Decision Tree depth/leaf constraints and SVM regularization must be selected using training-only validation, not repeated inspection of test accuracy.
3. **Feature scaling matters for SVM.** All four features are standardized using training-derived statistics; the Decision Tree does not require scaling.
4. **Two-feature plots are for interpretation.** Reported final Banknote scores use all four features, not the simplified 2D plotting models.
5. **Nonlinear kernels fit curved patterns more effectively.** On Two Moons, Polynomial and RBF SVMs substantially outperformed the Linear kernel.
6. **Small datasets and single splits have limitations.** Even perfect held-out and five-fold CV results do not guarantee performance under domain shift. Exact duplicates were grouped to reduce leakage, but independently sourced data would provide a stronger external validation.
